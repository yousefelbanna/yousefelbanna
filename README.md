# Yousef Elbanna

**Founder of [Norlay](https://norlay.fit/)** — an independent software brand building practical, accessible desktop apps for macOS and Windows.

I started Norlay to make useful software that is easier to use, with accessibility considered from the beginning rather than added later.

## What I’m building

### [Norlay](https://norlay.fit/norlay/) — everyday Mac tasks

An AI assistant for apps, files, the web, reminders, and your calendar. It includes 61 tools, an offline voice mode, and full VoiceOver support. **Available now for macOS.**

### [Norlay Code](https://norlay.fit/norlay-code/) — building software

A coding agent for Mac and Windows that works with real projects and shows changes as reviewable diffs. **Release pending.**
